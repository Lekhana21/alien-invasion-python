# Alien Invasion 🚀

A classic arcade-style shooting game developed using **Python** and **Pygame**, where the player controls a spaceship and shoots incoming aliens to protect the Earth.

## 📌 Project Overview

Alien Invasion is a 2D arcade game inspired by classic space-shooter games. The player controls a spaceship, fires bullets at alien fleets, and tries to achieve the highest possible score while avoiding defeat.

This project helped me practice Python programming, object-oriented programming, game loops, event handling, collision detection, and organizing a project into multiple modules.

## ✨ Features

- Spaceship movement using keyboard controls
- Bullet shooting mechanics
- Alien fleet generation and movement
- Collision detection between bullets and aliens
- Score tracking
- Player lives and game-over handling
- Increasing difficulty as the game progresses

## ⚙️ Installation and Setup

### 1. Clone the repository

```bash
git clone https://github.com/Lekhana21/alien-invasion-python.git
```

### 2. Navigate to the project directory

```bash
cd alien-invasion-python
```

### 3. Install Pygame

```bash
python -m pip install pygame
```

### 4. Run the game

```bash
python alien_invasion.py
```

Make sure Python is installed on your computer and that the game's image assets are included in the repository.

## 🎮 How to Play

- Use the arrow keys to move the spaceship.
- Press the spacebar to shoot bullets.
- Destroy aliens to earn points.
- Try to survive as long as possible.

*Adjust the controls if your game uses different keys.*
